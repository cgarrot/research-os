# adversarial-novelty-search

1. Steelman prior art: what WOULD this be called if known? Generate 5+ terminology hypotheses across communities (combinatorics, number theory, recreational, non-English).
2. Search transformed statements: complement form, shifted offset, scaled/reindexed parameters, the OBVIOUS weaker version people would have computed first.
3. Check adjacent repositories: OEIS crossrefs, dynamic surveys (Ramsey/van der Waerden style pages), competition records, theses.
4. If any probable match: mark `ambiguous`, store the near-miss, and design the distinguishing question (what would differentiate our claim?).
5. Only exhaustive failure across the full plan → `likely-new-after-audited-search` + human review bundle. Provider silence is never evidence.
