# change-representation

Triggers: repeated obstruction, low progress, stagnation.

1. List what information the problem actually preserves (parity structure, additive/multiplicative mixing, growth rate, invariants).
2. Try at least one distant encoding: sequence → generating function; iteration → 2-adic/functional view; arithmetic → graph on residues mod m; global claim → statistical/stopping-time profile; exact → modular shadow.
3. Map assumptions AND the target into the new representation before computing.
4. Prefer representations that expose invariants or connect to known theorem families.
5. Record each new representation as its own branch (`research_create_branch`) with method tags — even failures are negative memory worth keeping.
