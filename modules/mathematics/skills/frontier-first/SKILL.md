# frontier-first

1. `research_frontier_snapshot` with: target, frontierType, currentValue, the sources (type primary/curated/secondary + date + ref), the EXACT improvement predicate.
2. Get ≥2 independent sources for high-value targets. Same-class disagreement → `sourceAgreement: "conflict"` + a resolution task BEFORE hunting.
3. Records go stale in 24h: refresh the snapshot again immediately before any promotion — beating a STALE snapshot is not a record.
4. Derive the certificate spec from the predicate: object, validity, verifier (certificate-check / exhaustive-finite).
5. Reproduce the KNOWN frontier certificate when public — your validator must accept it before you trust it on new candidates.
